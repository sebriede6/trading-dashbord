# Security

Bitte keine Sicherheitslücken öffentlich als GitHub Issue melden.

Melde sie privat über die Security-Advisories-Funktion des Repositorys oder über den im GitHub-Profil hinterlegten Kontakt.

Melde keine Passwörter, Tokens, privaten Schlüssel oder personenbezogenen Tradingdaten im Issue oder Pull Request.

Bei einem versehentlich veröffentlichten Secret muss es sofort widerrufen und ersetzt werden. Das Entfernen aus einer Datei reicht nicht aus, wenn es bereits in der Git-Historie enthalten war.
